## Projetos em destaque

### [SalesForecast](https://github.com/kevin16willian-hub/SalesForecast)

Aplicação corporativa para previsão de vendas, desenvolvida com React, Node.js e SQL Server. Conta com autenticação corporativa via Microsoft Entra ID, upload e validação de planilhas Excel, API REST protegida com controle de acesso hierárquico e deploy automatizado na AWS EC2.

**Impacto:** utilizada diariamente por cerca de **150 colaboradores**, com potencial de economia de **R$ 145 mil por mês (R$ 1,7 milhão por ano)**.

### [FlowCraft](https://github.com/kevin16willian-hub/FlowCraft)

Ferramenta oficial da **Straumann** para mapeamento de processos e colaboração visual, construída com React Flow, Server-Sent Events (SSE) e armazenamento na AWS S3.

**Impacto:** usada diariamente por cerca de **500 colaboradores** e gera uma economia de **US$ 10 mil por mês** em licenças da ferramenta anterior.

### [SapRecorder](https://github.com/kevin16willian-hub/SapRecorder)

Aplicação Python para gravar interações com o SAP GUI Scripting e gerar código reutilizável para automações. Permite que os próprios clientes registrem os scripts necessários às suas soluções, agilizando e descentralizando essa etapa do processo. Ela é integrada ao FlowCraft
