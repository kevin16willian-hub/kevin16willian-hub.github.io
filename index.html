Uno visão de negócio e engenharia de software para transformar problemas operacionais em soluções que fazem diferença no dia a dia.

Projetos em destaque

SalesForecast

Aplicação corporativa para previsão de vendas, desenvolvida com React, Node.js e SQL Server. Conta com autenticação corporativa via Microsoft Entra ID, upload e validação de planilhas Excel, API REST protegida com controle de acesso hierárquico e deploy automatizado na AWS EC2.

Impacto: ~150 colaboradores por dia · economia potencial de R$ 145 mil/mês (R$ 1,7 milhão/ano)

FlowCraft

Ferramenta oficial da Straumann para mapeamento de processos e colaboração visual, construída com React Flow, Server-Sent Events (SSE) e armazenamento na AWS S3.

Impacto: ~500 colaboradores por dia · US$ 10 mil/mês economizados em licenças da ferramenta anterior

SapRecorder

Aplicação Python para gravar interações com o SAP GUI Scripting e gerar código reutilizável para automações. Permite que os próprios clientes registrem os scripts necessários às suas soluções, agilizando e descentralizando essa etapa do processo. Integrada ao FlowCraft.

Engenharia de IA, automação e qualidade

Exploro abordagens AI-first para acelerar o desenvolvimento de software e automatizar fluxos de trabalho, integrando modelos, ferramentas e sistemas corporativos. Tenho interesse especial em agentes de IA, no ecossistema MCP e em práticas de qualidade que ajudem a criar soluções confiáveis, testáveis e úteis em produção.

  • IA generativa e agentes: implementação de agentes com Amazon Bedrock e AgentCore, conectando recursos de IA a ferramentas e fluxos de trabalho.
  • Model Context Protocol (MCP): integração de modelos com ferramentas, dados e serviços por meio do protocolo MCP.
  • Testes automatizados: automação de testes end-to-end e regressivos com Playwright e Python para validar fluxos críticos.
  • Automação de processos: criação de automações que conectam aplicações, APIs e sistemas corporativos.
  • Engenharia de dados: pipelines e processamento de dados com PySpark, AWS Glue, Athena e Snowflake.
